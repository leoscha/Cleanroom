# Brand and demonstration assets

- `logo.svg` and `icon.svg` are editable project-native vector assets.
- `banner.png` was generated for the v0.2.0 release with OpenAI's built-in image
  generation tool, then copied into the repository without further editing.
- `screenshots/*.png` and `terminal-demo.gif` contain synthetic output and are
  reproducibly generated by `scripts/generate_demo_assets.py`.

Banner generation prompt:

> Create a clean, modern, privacy-focused wide GitHub banner for Cleanroom, a
> local-first AI Privacy Gateway. Show an abstract minimal document passing through a
> protective shield with a check motif, emerging clean and safe. Use a refined flat,
> vector-like style; deep slate, navy, cobalt, cyan, and off-white; exact text
> “CLEANROOM” and “LOCAL-FIRST AI PRIVACY GATEWAY”; no other brands, watermark,
> people, lock imagery, cyberpunk effects, or clutter.

Regenerate terminal media after changing sample CLI output:

```bash
python scripts/generate_demo_assets.py
```
