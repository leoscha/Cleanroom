# Cleanroom v0.2.1 — Text Foundation Stabilization

v0.2.1 strengthens the release gates around Cleanroom's existing text foundation. It
does not add a new sanitization format or change the local-first security model.

## Highlights

- 120 reproducible synthetic regression cases, bringing the bundled suite to 128
  total text and generated-PDF cases.
- Deterministic CI gates for precision, required recall, exact spans, verification,
  invalid findings, and PDF mapping/redaction/verification.
- Test execution on Linux, macOS, and Windows.
- Clean wheel build and isolated-install smoke testing in CI.
- Fixed IPv4 sentence-punctuation handling while preserving rejection of malformed
  five-component addresses.

## Validation target

The deterministic release gate requires 1.000 precision, 1.000 required-finding
recall, at least 0.950 exact-span accuracy, a 1.000 verification pass rate, no invalid
findings, and perfect generated-PDF mapping, redaction, and verification rates.

Contextual Ollama results remain model-, prompt-, and hardware-specific and are
reported separately from deterministic CI.

## Upgrade

```bash
python -m pip install --upgrade cleanroom-local==0.2.1
cleanroom version
cleanroom doctor
cleanroom evaluate --detector regex
```

Expected version output:

```text
Cleanroom v0.2.1
```

No configuration or database migration is required from v0.2.0. Existing explicit
Ollama connection modes continue to work unchanged.

## Security boundary

This release does not make probabilistic detection exhaustive. OCR and scanned PDFs
remain unsupported, unusual PDF structures may be quarantined, and human review may
still be required.
