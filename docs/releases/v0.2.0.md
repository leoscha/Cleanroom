# Cleanroom v0.2.0 — Text Foundation

Cleanroom's first public release establishes a reliable local-first foundation for
sanitizing sensitive information before text is shared with AI systems.

## Highlights

- Local Ollama is the zero-configuration default.
- Deterministic detectors and a private model find direct and contextual identifiers.
- Repeated values receive consistent placeholders while surrounding labels survive.
- Verification rescans sanitized output and quarantines uncertainty.
- Reports contain counts, hashes, timing, and safe next actions—not matched plaintext.
- `cleanroom doctor`, `demo --run`, `scan`, `status`, `show`, and `evaluate` provide a
  complete operator workflow.
- Remote Ollama remains available through explicit private-network and custom modes.

## Install

```bash
git clone https://github.com/leoscha/Cleanroom.git
cd Cleanroom
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
cleanroom init
ollama pull gemma3:4b
cleanroom doctor
cleanroom demo --run
```

## Security posture

Cleanroom defaults to loopback inference, rejects public endpoints and unsafe DNS
answers, never exposes Ollama, avoids plaintext findings in normal reports, and fails
closed when verification or policy review is unresolved.

Cleanroom reduces risk; it does not guarantee complete detection. OCR, image-only
PDFs, unsupported formats, and forensic PDF sanitization are outside this release's
guarantees. Review [security](../../SECURITY.md) and [philosophy](../philosophy.md)
before production use.
